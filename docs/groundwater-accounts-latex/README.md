# NERACA: Groundwater Accounts — sources

Research report and app design for the A + B + C pivot (groundwater accounts and tax, inspection leads,
pipes instead of pumps). Research basis: `../groundwater-audit-latex-v2/experiments/15-app-pivot-a-b-c.md`
and files 04-14 of that log.

Build the PDF:   cd tex && pdflatex main && pdflatex main   (TeX Live or MiKTeX; needs tcolorbox, xltabular, needspace)
